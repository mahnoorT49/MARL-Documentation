\doxysubsection{Detailed Description}
The cgroup filesystem superblock creation/\+mount context.

struct Description:\+ This structure holds the filesystem context for cgroup mounts. It contains the cgroup root, namespace, flags, and cgroup1-\/specific options like cpuset\+\_\+clone\+\_\+children, subsystem mask, name, and release agent path. It is used during cgroup filesystem mounting and remounting.
