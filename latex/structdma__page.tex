\doxysubsection{Detailed Description}
struct Description:\+ This structure represents a page of memory allocated for a DMA pool. It contains the page list linkage, the virtual address of the page, and the DMA address. Each page is split into multiple blocks of the pool\textquotesingle{}s size.
