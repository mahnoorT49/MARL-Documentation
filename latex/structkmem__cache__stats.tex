struct Description:\+ This structure holds per-\/\+CPU statistics counters for a \doxylink{structkmem__cache}{kmem\+\_\+cache} when CONFIG\+\_\+\+SLUB\+\_\+\+STATS is enabled. It contains an array stat of unsigned integers indexed by enum \doxylink{slub_8c_a941fceda51e3eafd88dec169928b92a3}{stat\+\_\+item}, which includes counters for various allocator events such as fastpath/\+slowpath allocations and frees, partial list operations, sheaf operations, barn operations, and other performance metrics.
