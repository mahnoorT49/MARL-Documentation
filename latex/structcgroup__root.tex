struct Description:\+ This structure represents the root of a cgroup hierarchy. It contains the subsystem mask, hierarchy ID, flags, release agent path, name, and the root cgroup. Each mounted cgroup filesystem has one \doxylink{structcgroup__root}{cgroup\+\_\+root}.
