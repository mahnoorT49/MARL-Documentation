Enumeration Description:\+ This enumeration defines the mount options available for cgroup1 (legacy) filesystems. Each value represents a specific mount parameter that can be passed during cgroup mount or remount operations. void cgroup1\+\_\+release\+\_\+agent (\begin{DoxyParamCaption}\item[{struct work\+\_\+struct \texorpdfstring{$\ast$}{*}}]{work}{}\end{DoxyParamCaption})}

Notify userspace when a cgroup is released, by running the configured release agent with the name of the cgroup (path relative to the root of cgroup file system) as the argument.

Most likely, this user command will try to rmdir this cgroup.

This races with the possibility that some other task will be attached to this cgroup before it is removed, or that some other user task will \textquotesingle{}mkdir\textquotesingle{} a child cgroup of this cgroup. That\textquotesingle{}s ok. The presumed \textquotesingle{}rmdir\textquotesingle{} will fail quietly if this cgroup is no longer unused, and this cgroup will be reprieved from its death sentence, to continue to serve a useful existence. Next time it\textquotesingle{}s released, we will get notified again, if it still has \textquotesingle{}notify\+\_\+on\+\_\+release\textquotesingle{} set.

The final arg to call\+\_\+usermodehelper() is UMH\+\_\+\+WAIT\+\_\+\+EXEC, which means only wait until the task is successfully execve()\textquotesingle{}d. The separate release agent task is forked by call\+\_\+usermodehelper(), then control in this thread returns here, without waiting for the release agent task. We don\textquotesingle{}t bother to wait because the caller of this routine has no use for the exit status of the release agent task, so no sense holding our caller up for that.

Function Description:\+ Work function for the cgroup1 release agent. It builds the command line with the release agent path and cgroup path, then executes it using call\+\_\+usermodehelper().
