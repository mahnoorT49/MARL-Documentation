\doxysubsection{Detailed Description}
Per-\/subsystem/\+per-\/cgroup state maintained by the system. This is the fundamental structural building block that controllers deal with.

Fields marked with "{}\+PI:\+"{} are public and immutable and may be accessed directly without synchronization.

struct Description:\+ This is the main structure representing per-\/subsystem state for a cgroup. It contains the reference count, pointer to the cgroup and subsystem, lists for parent-\/child relationships, rstat data, and various flags. Controllers use this to store their state for each cgroup.
