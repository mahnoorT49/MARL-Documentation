css\+\_\+tryget -\/ try to obtain a reference on the specified css @css:\+ target css

Obtain a reference on @css unless it already has reached zero and is being released. This function doesn\textquotesingle{}t care whether @css is on or offline. The caller naturally needs to ensure that @css is accessible but doesn\textquotesingle{}t have to be holding a reference on it -\/ IOW, RCU protected access is good enough for this function. Returns true if a reference count was successfully obtained; false otherwise.

Function Description:\+ Tries to increase the reference count of a cgroup subsystem state. It attempts to get a reference only if the CSS has not reached zero and is not being released. Returns true if the reference was obtained, false otherwise. This can be called without holding a reference as long as the CSS is accessed under RCU protection.
