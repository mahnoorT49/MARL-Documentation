\doxysubsection{Detailed Description}
Slab cache management.

struct Description:\+ This is the main structure representing a slab cache in the SLUB allocator. It contains per-\/\+CPU sheaves, flags, min\+\_\+partial count, object sizes, free pointer offset, sheaf capacity, order and min objects, allocation flags, refcount, constructor, alignment, redzone padding, name, and per-\/node data. Each cache manages a set of slabs of the same object size.
