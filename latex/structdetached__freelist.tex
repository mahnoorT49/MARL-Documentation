\doxysubsection{Detailed Description}
struct Description:\+ This structure represents a detached freelist built during bulk free. It contains the slab pointer, tail pointer, freelist head, count, and \doxylink{structkmem__cache}{kmem\+\_\+cache}. It is used to batch free operations for objects from the same slab.
