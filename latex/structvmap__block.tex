\doxysubsection{Detailed Description}
struct Description:\+ This structure represents a block of virtual memory used by \doxylink{vmalloc_8h_acd02620225f5b290f8935dbc1e45b18e}{vm\+\_\+map\+\_\+ram()}. It contains the \doxylink{structvmap__area}{vmap\+\_\+area}, a bitmap of used pages, free/\+dirty counters, dirty range, list linkage, and CPU affinity. It is used to manage small allocations within a larger VMAP\+\_\+\+BLOCK\+\_\+\+SIZE region.
