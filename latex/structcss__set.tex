\doxysubsection{Detailed Description}
A \doxylink{structcss__set}{css\+\_\+set} is a structure holding pointers to a set of \doxylink{structcgroup__subsys__state}{cgroup\+\_\+subsys\+\_\+state} objects. This saves space in the task struct object and speeds up fork()/\+exit(), since a single inc/\+dec and a list\+\_\+add()/\+del() can bump the reference count on the entire cgroup set for a task.

struct Description:\+ This structure holds a set of pointers to \doxylink{structcgroup__subsys__state}{cgroup\+\_\+subsys\+\_\+state} objects for all subsystems. It saves space in task structures and speeds up fork/\+exit operations. Tasks that share the same cgroup configuration use the same \doxylink{structcss__set}{css\+\_\+set}.
