Function Description:\+ Allocates memory of the given size using malloc(). It first checks if memory reclaim is allowed; if not, it returns NULL. After allocation, it increases the global counter to track how many allocations are active. If verbose mode is on, it prints the address of the allocated memory. If the \+\_\+\+\_\+\+GFP\+\_\+\+ZERO flag is set, it fills the memory with zeros before returning the pointer.
