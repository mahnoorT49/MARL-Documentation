\doxysubsection{Detailed Description}
\doxylink{structcgroup__file}{cgroup\+\_\+file} is the handle for a file instance created in a cgroup which is used, for example, to generate file changed notifications. This can be obtained by setting cftype-\/\texorpdfstring{$>$}{>}file\+\_\+offset.

struct Description:\+ This structure is a handle for a file instance created in a cgroup. It contains the kernfs node pointer, notification timestamp, and a timer for generating file changed notifications. It is used to notify userspace when cgroup state changes.
