\doxysubsection{Detailed Description}
rstat -\/ cgroup scalable recursive statistics. Accounting is done per-\/cpu in \doxylink{structcss__rstat__cpu}{css\+\_\+rstat\+\_\+cpu} which is then lazily propagated up the hierarchy on reads.

When a stat gets updated, the \doxylink{structcss__rstat__cpu}{css\+\_\+rstat\+\_\+cpu} and its ancestors are linked into the updated tree. On the following read, propagation only considers and consumes the updated tree. This makes reading O(the number of descendants which have been active since last read) instead of O(the total number of descendants).

This is important because there can be a lot of (draining) cgroups which aren\textquotesingle{}t active and stat may be read frequently. The combination can become very expensive. By propagating selectively, increasing reading frequency decreases the cost of each read.

This struct hosts both the fields which implement the above -\/ updated\+\_\+children and updated\+\_\+next.

struct Description:\+ This structure holds per-\/\+CPU rstat data for a cgroup subsystem state. It maintains lists of updated children and is used for scalable statistics propagation. Updates are done per-\/cpu and propagated lazily on reads.
