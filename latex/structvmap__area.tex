\doxysubsection{Detailed Description}
struct Description:\+ This structure represents a virtual memory area in the vmalloc space. It contains the start and end addresses, rb\+\_\+tree and list nodes for tracking, and either subtree\+\_\+max\+\_\+size (when free) or \doxylink{structvm__struct}{vm\+\_\+struct} pointer (when busy). It is used internally by the vmalloc subsystem to manage the virtual address space.
