\doxysubsection{Detailed Description}
General purpose special memory pool chunk descriptor.

struct Description:\+ This structure represents a single chunk of memory within a \doxylink{structgen__pool}{gen\+\_\+pool}. It contains the physical and virtual addresses, available space counter, a bitmap for tracking allocated/\+free blocks, and private owner data. Each chunk is linked into the pool\textquotesingle{}s list of chunks.
