Detailed Description

A cgroup_root represents the root of a cgroup hierarchy, and may be associated with a kernfs_root to form an active hierarchy. This is internal to cgroup core. Don't access directly from controllers.

struct Description: This structure represents the root of a cgroup hierarchy. It contains the subsystem mask, hierarchy ID, flags, release agent path, name, and the root cgroup. Each mounted cgroup filesystem has one cgroup_root.
