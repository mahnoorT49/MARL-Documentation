Detailed Description

This struct hosts the fields which track basic resource statistics on top of it - bsync, bstat and last_bstat.

struct Description: This structure holds per-CPU basic resource statistics for a cgroup. It includes CPU time statistics, synchronization fields, and snapshots for calculating deltas. These statistics are used for tracking CPU usage of cgroups.
