Detailed Description

struct cftype: handler definitions for cgroup control files

When reading/writing to a file:

  • the cgroup to use is file->f_path.dentry->d_parent->d_fsdata
  • the 'cftype' of the file is file->f_path.dentry->d_fsdata

struct Description: This structure defines handler functions for cgroup control files. It contains the file name, flags, and callback functions for read/write operations. Controllers use this to create interface files in cgroup directories.
