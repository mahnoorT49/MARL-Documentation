Detailed Description

CONFIG_CGROUPS sock_cgroup_data is embedded at sock->sk_cgrp_data and contains per-socket cgroup information except for memcg association.

On legacy hierarchies, net_prio and net_cls controllers directly set attributes on each sock which can then be tested by the network layer. On the default hierarchy, each sock is associated with the cgroup it was created in and the networking layer can match the cgroup directly.

struct Description: This structure holds per-socket cgroup information for network controllers. It contains the cgroup pointer for v2, and classid and prioidx for v1 controllers. The network layer uses this to enforce network policies based on cgroups.
